# Basic theory
Total population movement is not matched with age-stratified population movement. 

Population change for total population
= (Birth – death) + (move_in – move_out) + other factors.

Population change for specific age= (in_age_min – out_age_max) + (move_in – move_out) + other factors


- Move_in and move_out data is available based on 住民基本台帳 for Kumamoto (after 2024)

# Cohort change ratio (CCR) method, validation check
Taking a diff for each 1-year age band and death data to obtain the net migration rate. 
1D version is saved in 4r, and 2D pclm in 5r. 

The quality of CCR method can be compared in Kumamoto city. 
![Caption](../res/5r_11_kumamoto_residual_vs_reported_2d.png)

The reported age profile of net migration rate has some bumping structure. 
![Caption](../res/5r_08_kumamoto_age_profile_reported_vs_2d.png)

Note: the following is a possible solution to improve this bumping behaviour: 

> A good fit is a penalized composite-link cohort-component model: a state-space model where a smooth single-year population moves forward one year through survival plus a smooth migration schedule, and both years’ 5-year counts are fitted together. It combines three established ideas: ungrouping with the penalized composite link model (PCLM), demographic accounting, and smoothness priors.

As a result, the detailed diverged stacked bar plot becomes pretty dirty but grouping 50+ can mitigate this effect.

Claude interpretation of this figure: 
2016-2020 wide range of reduction trends would be due to 
> (a) 復興需要の時期と一致している 国の復興政策は、**集中復興期間（2011〜2015年度）と復興・創生期間（2016〜2020年度）**に分かれています。インフラ・防潮堤・かさ上げ・災害公営住宅などの大型事業は前半に集中し、後半に向けて縮小しました。図の③（2013–15、青）から④（2016–20、オレンジ）への切り替わりは、この区切りとほぼ重なります。  
> (b) 流入していた人が出ていく 復興期には、建設業の技術者や作業員、応援の自治体職員などが流入しました。事業が終わると、その人たちが転出します。ただし短期の作業員は住民票を移さないことが多いので、この効果は住民基本台帳では一部しか見えない点に注意が必要です。  
> (c) 抑えられていた若年層の流出が戻る（繰り延べ・追いつき） 復興期は地元の求人が多く、賃金も高かったため、高卒・大卒の地元就職が増え、若年層が地域に残りやすい状況でした。また、被災した家族の生活再建のために、進学や就職での転出を先送りした人もいたと考えられます。復興需要が落ち着くと、こうして先送りされていた流出がまとめて出てくるので、一時的に震災前の水準を超える流出になり得ます。  
> (d) 住宅再建の完了・断念 高台移転や区画整理は完成までに5〜8年かかった地域が多く、待っている間に別の場所で生活を立て直した人が、最終的に住民票を移すタイミングがこの時期に重なります。また、仮設住宅が閉鎖されたことも転出のきっかけになります。
